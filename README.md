I'm working my way toward a career as a **backend engineer**. I like the parts of software most people never see: APIs, services, and the tools that keep things running. My goal is to build systems that are simple, reliable, and fast.

Most of my time goes into **Go**. I'm getting better at writing clean, well-tested code and learning how real production systems are put together.
